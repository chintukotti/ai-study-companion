# AI Study Companion — API Reference

Base URL: `http://localhost:3001/api`

All protected endpoints require an `Authorization` header with a Supabase JWT:
`Authorization: Bearer <access_token>`

---

## 1. Authentication & Profiles (`/auth`)

### `GET /auth/me`
Returns profile of authenticated user.
- **Response**: `200 OK`
```json
{
  "id": "uuid",
  "email": "student@example.com",
  "full_name": "Jane Doe",
  "role": "user"
}
```

### `PATCH /auth/profile`
Updates user profile.
- **Body**: `{ "fullName": "Jane Doe", "avatarUrl": "https://..." }`
- **Response**: `200 OK`

---

## 2. Spaces (`/spaces`)

### `GET /spaces`
Lists all spaces the authenticated user is a member of.
- **Response**: `200 OK` (Array of Spaces with `member_count`, `project_count`)

### `POST /spaces`
Creates a new study space.
- **Body**: `{ "name": "Computer Science 101", "description": "Introductory CS courses" }`
- **Response**: `201 Created`

### `GET /spaces/:id`
Gets space details, member list, and role.
- **Response**: `200 OK`

### `PATCH /spaces/:id`
Updates space metadata (owner or admin only).

### `DELETE /spaces/:id`
Deletes space and cascades all nested projects/documents (owner only).

---

## 3. Projects (`/spaces/:spaceId/projects`, `/projects/:id`)

### `GET /spaces/:spaceId/projects`
Lists all projects within a space.
- **Response**: `200 OK`

### `POST /spaces/:spaceId/projects`
Creates a new project within a space.
- **Body**: `{ "name": "Data Structures & Algorithms", "description": "Trees, Graphs, Sorting" }`
- **Response**: `201 Created`

### `GET /projects/:id`
Gets project metadata and document counts.

### `DELETE /projects/:id`
Deletes a project and associated documents, quizzes, and embeddings.

---

## 4. Documents & Ingestion (`/projects/:projectId/documents`, `/documents/:id`)

### `POST /projects/:projectId/documents`
Uploads a PDF file (multipart/form-data, max 25MB).
- Triggers asynchronous OCR and text extraction via Python microservice.
- Generates 768-dim embeddings with Gemini `text-embedding-004`.
- **Response**: `202 Accepted`

### `GET /projects/:projectId/documents`
Lists all documents in the project with processing status (`uploading`, `processing`, `ready`, `failed`).

### `GET /documents/:id/status`
Gets current extraction and embedding job progress (`progress: 0-100`, status, error).

### `DELETE /documents/:id`
Removes document from Supabase storage and cascades vector chunks from `document_chunks`.

---

## 5. AI Tutor & RAG (`/projects/:projectId/tutor`)

### `POST /projects/:projectId/tutor/chat`
Sends a query to the AI Tutor.
- **Body**:
```json
{
  "message": "Explain Dijkstra's algorithm and provide the page reference.",
  "sessionId": "optional-uuid"
}
```
- **Response**: `200 OK`
```json
{
  "sessionId": "uuid",
  "message": {
    "role": "assistant",
    "content": "Dijkstra's algorithm finds the shortest path [Page 42]...",
    "citations": [
      {
        "document_id": "uuid",
        "page_number": 42,
        "quote": "Dijkstra's algorithm computes single-source shortest paths..."
      }
    ]
  },
  "isUnsupported": false,
  "unsupportedReason": null,
  "topicsDiscussed": ["Graph Theory", "Dijkstra Algorithm"]
}
```

### `GET /projects/:projectId/tutor/sessions`
Lists user's chat sessions in this project.

### `GET /tutor/sessions/:id/messages`
Retrieves chat history for a session.

---

## 6. Adaptive Quizzes (`/projects/:projectId/quizzes`, `/quizzes/:id`)

### `POST /projects/:projectId/quizzes/generate`
Generates an AI-powered quiz adapted to the user's mastery level and Bloom's taxonomy.
- **Body**:
```json
{
  "topic": "Binary Search Trees",
  "type": "mcq",
  "difficulty": "intermediate",
  "questionCount": 5
}
```
- **Response**: `201 Created`

### `GET /quizzes/:id`
Retrieves quiz questions.

### `POST /quizzes/:id/submit`
Submits student answers for evaluation. MCQ evaluated directly; open-ended answers evaluated by Gemini. Updates concept mastery automatically.
- **Body**:
```json
{
  "answers": [
    {
      "questionId": "uuid",
      "answer": "Option text",
      "selectedOptionIndex": 1
    }
  ]
}
```
- **Response**: `200 OK` with score, breakdown, and feedback.

---

## 7. Mastery & Growth (`/projects/:projectId/mastery`, `/projects/:projectId/growth`)

### `GET /projects/:projectId/mastery`
Retrieves concept mastery percentages and attempt counts.

### `GET /projects/:projectId/growth`
Returns historical mastery snapshots over time.

### `GET /projects/:projectId/recommendations`
Returns personalized next-action recommendations generated by AI based on weak areas.

---

## 8. Analytics & Admin (`/analytics`, `/admin`)

### `GET /projects/:projectId/analytics`
Project overview stats (documents, chats, quizzes, avg score, overall mastery).

### `GET /analytics/activity`
Activity event timeline.

### `GET /admin/stats` (Admin only)
System-wide counts and operational metrics.

### `GET /admin/users` (Admin only)
List registered users and roles.

### `GET /admin/ai-usage` (Admin only)
Aggregated AI token consumption, latency, and cost estimates.
